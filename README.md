# EcoMind

This is a high-school level prototype of an AI system that checks water quality.

## What it does:
* It reads water sensor data like pH, temperature, and muddiness.
* It predicts if there are heavy metals in the water.
* It forecasts if harmful bacteria are likely to grow.

## Built with:
* Python
* Google Colab
* Machine Learning (Random Forest)
